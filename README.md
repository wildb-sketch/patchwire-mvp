# Whassabi Android test APKs

[Download the latest Whassabi APK — volume buttons and notification icons](https://github.com/wildb-sketch/patchwire-mvp/raw/refs/heads/android-test-download-20261117/whassabi-volume-buttons-fix.apk)

Install over the previous APK; signing identity and launcher logo are retained. With Whassabi open in an active room, Volume Up/Down now explicitly adjust media playback volume instead of Android choosing a different stream in communication mode. Releasing a button does not adjust twice; holding it repeats normally. Outside a room and during ringing/telephone calls, Android handles the keys normally. No volume is raised automatically, and microphone gain/routing are unchanged.

Room and social notifications now use a monochrome Whassabi small icon and the existing full-color launcher artwork as the large icon. Android/OEM templates determine tint and placement, so Samsung and Huawei may still arrange them differently. Mute/Unmute and Leave controls remain intact.

Source: [PR #21](https://github.com/wildb-sketch/patchwire-mvp/pull/21), merged as `e56d6ca00590a219df11fb6bc1bf14c6762734b0` from tested head `71007225c3c997f3f5cae9a14cdefeac8011bab6`. [GitHub checks](https://github.com/wildb-sketch/patchwire-mvp/actions/runs/44686928307) passed Android assembly/lint, 63 native tests, 160 Node tests, 5 Workers runtime tests and 10 browser/WebRTC tests. The artifact digest and persistent APK signing fingerprint were verified before publication.

Physical validation is still required: while the tablet speaks and Whassabi is open on the Samsung Note 10+, press Volume Down/Up and confirm actual loudness plus the Media volume indicator. Check the notification artwork, then repeat as a muted speaker/listener and with earbuds connected/disconnected. Leave and verify normal volume-button behavior. Background/lock-screen keys remain controlled by Android and need separate device validation.

Diagnostics show native build `android-media-volume-1` and separate media/call volume indices. **Profile → Broadcast & Audio Hardware → Copy audio diagnostics** opens a local report; if automatic copying is blocked, long-press the report and use Select all → Copy. No report is uploaded automatically. [Detailed testing notes](https://github.com/wildb-sketch/patchwire-mvp/blob/main/mobile/ANDROID-VOICE-TESTING.md).
