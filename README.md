# Whassabi Android test APKs

[Download the latest Whassabi APK — Android 12 loudspeaker compatibility](https://github.com/wildb-sketch/patchwire-mvp/raw/refs/heads/android-test-download-20261117/whassabi-android12-audio-compat.apk)

Install over the previous APK; its signing identity and logo are retained. Reopen the tablet app too so both devices load the updated web client.

Android 12/12L phone output now uses the speakerphone compatibility control, including when unplugging HFP temporarily removes the speaker from the communication-device list. Bluetooth and wired headsets keep the modern routing API; Android 13+ phone output also keeps that API. Watch filtering, saved output choices, mute state and stable microphone generations remain in place. Standard automatic speech gain is enabled again in both designs to address quiet tablet transmission; no fixed gain multiplier is applied.

Source: [PR #19](https://github.com/wildb-sketch/patchwire-mvp/pull/19), merged as `c29f5ada2c20f8b2eaec982479c6e9e4b3e6c097` from tested head `2c15b7cb8fb708cb1d06c79fd994029df2dd55c8`. [GitHub checks](https://github.com/wildb-sketch/patchwire-mvp/actions/runs/44634207605) passed Android assembly/lint, 50 native tests, 158 Node tests, 5 Workers runtime tests and 10 browser/WebRTC tests.

Physical validation is still required on the Samsung Note 10+ / Android 12: connect and disconnect earbuds while in a room with the watch paired, then verify loudspeaker playback and phone microphone transmission without rejoining. Compare tablet-to-phone speech level at similar distances. Automated tests do not emulate the Samsung driver, Bluetooth radio or actual earbud microphone.

If it still fails, use **Profile → Broadcast & Audio Hardware → Copy audio diagnostics** while the failure is present. This copies a bounded local report with platform/WebView versions, route state and audio processing/counters. It excludes account/room identities, credentials, SDP/candidates and device identifiers; it is never uploaded automatically. Share it only when seeking help. [Detailed testing notes](https://github.com/wildb-sketch/patchwire-mvp/blob/main/mobile/ANDROID-VOICE-TESTING.md).
